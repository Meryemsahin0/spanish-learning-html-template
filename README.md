# spanish-learning-html-template# 
🇪🇸 Mi Español – A1'den B2'ye

Bu proje, İspanyolca öğrenme yolculuğumu takip etmek, kelime dağarcığımı geliştirmek ve dil bilgisi notlarımı düzenlemek için geliştirdiğim kapsamlı bir web uygulamasıdır. 

## ✨ Özellikler
- 🗺️ **Yol Haritası:** A1 seviyesinden B2'ye kadar olan ilerlemeyi görsel olarak takip etme.
- 🗂️ **Kelime Kartları:** Kategori bazlı, çevirmeli interaktif kelime çalışma alanı.
- 📝 **Eğitim Bloğu:** Dil öğrenme sürecine dair notlar ve yorum sistemi.
- 🧠 **Quiz Modülü:** Bilgileri test etmek için interaktif soru-cevap yapısı.
- 🔐 **Admin Paneli:** İçerikleri (kelime, blog, seviye detayları) yönetmek için özel kontrol alanı.
- 📱 **Responsive Tasarım:** Mobil ve masaüstü cihazlarla tam uyumlu arayüz.

## 🛠️ Kullanılan Teknolojiler
- **Frontend:** HTML5, CSS3 (Custom Variables), Vue.js (v3)
- **Tasarım:** Playfair Display & Outfit Tipografisi
- **İkonlar:** Emoji tabanlı hafif tasarım

## 🚀 Kurulum ve Kullanım
Projeyi yerel makinenizde çalıştırmak için:
1. Depoyu klonlayın: `git clone https://github.com/kullanici-adin/ispanyolca-ogrenme-portali.git`
2. `espanol-v4(2).html` dosyasını herhangi bir modern tarayıcıda açın.
